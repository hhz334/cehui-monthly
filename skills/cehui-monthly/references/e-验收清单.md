- [ ] 封面第 1 行是**红字刊名**（方正小标宋简体 36pt／C00000），第 2 行是日期／第 N 期／编制单位。
- [ ] 正文页眉：栏目名居中＋底边框，栏名上方留空行；中英文字体黑体。
- [ ] 三栏目齐全；正文为全文；正文分段与源文一致（一行即一段）。
- [ ] **固定规则生效**：正文**无“原文链接：”行**（链接在目录表与 `02_原文` 里）；**文末无署名**（（刘某）、（单位 单位）、
      `××/摄`、`×× 供图`、图片说明行）；正文里的“（详见下表）”类说明**未被误删**。
- [ ] **每篇文章另起一页**：每个 `【省份】标题` 都从新页开始（板块首条由分节符另页）；**无空白页**
      （`render_and_check.py` 体检项“无空白页”为 0 个）。
- [ ] 目录页码与正文实际页码一致（`_make_issue.py` 收敛后 `定位 16/16`）。
- [ ] **目录可点击跳转（WPS 也要能点）**：`34_add_toc_links.py` 已就地执行（默认 `--style field`，域写法）；
      文档里链接域数＝书签数＝目录条目数；**在 WPS 里抽 3 条点击**确认能跳（Word 原生 anchor 写法在 WPS 会报
      “无法打开指定文件”）；导出 PDF 后链接注释数与条目数一致。
- [ ] 目录标注页码＝目标页**页脚**“— N —”的页码（不是 PDF 物理页序）；重排或加页后必须重跑 34。
- [ ] **页脚域缓存已刷新**（`39_fix_footer_page_cache.py` 已跑）：各分节页脚部件的 `PAGE` 缓存值＝该节首页页码
      （政策法规＝1、技术应用类＝第一节页数+1、科技前沿类依次递增），`settings.xml` 里有 `updateFields`；
      否则 WPS 会按旧缓存显示页码、与目录对不上。
- [ ] **页脚版式**（`40_fix_footer_layout.py` 已跑）：渲染后页码“— N —”水平居中（中心≈页面中心），
      各板块距页底一致（58.6pt）；模板与 `.dotx` 也同步修过。
- [ ] **字体是原版**（`41_export_pdf.py` 导出）：PDF 字体表里是 `仿宋_GB2312`／`楷体_GB2312`／`黑体`／
      `方正小标宋简体`／Times New Roman，**没有** `MicrosoftYaHei` 之类顶替字体；缺字体时脚本会报警，先装字体再重导。
- [ ] `来源：` 行数＝`原文链接：`数＝目录条数；无空节、无空白页、无越界。
- [ ] 导出 `测绘动态工作_<期号>.docx`／`.pdf` 与逐页 PNG 预览；交付说明写明页数与条数。
- [ ] **文本核校**：`27_text_qa.py` 对成稿出《文本体例检查.md》；`33_fix_docx_text.py` 出 `_核校版.docx`。
      核校版应满足：汉字与字母/数字之间空格 0、特殊空白只剩页眉的 `\u3000`、引号书名号括号全部配对、
      无汉字间半角标点；法条标题（`第一章 总 则`）与引号内标语的空格**保留**。
