# 《中国自然资源报》取文渠道与方法（实测版）

> 实测时间：2026-09-15
> 实测网络：本机直连（无需代理、无需登录）
> 结论：**官网（i自然）与数字报两条线全部打通，可直接批量取标题、正文、版面与 PDF；公众号单篇可读，但批量枚举受限。**

---

## 一、结论速览

| 通道 | 入口 | 能拿到什么 | 是否需要登录 | 推荐度 |
| --- | --- | --- | --- | --- |
| A. i自然官网 | `https://www.iziran.net` + `https://api.iziran.net` | 栏目文章列表、单篇完整正文（HTML/纯文本）、作者、发布时间 | 否 | ★★★★ 日常采集主力 |
| B. 数字报（报纸电子版） | `https://szb.iziran.net` | 版面清单、每版 PDF 与高清大图、**全库文章全文检索**、历史报纸回溯 | 匿名会话即可（`ipLogin` 一次） | ★★★★★ 最权威、可检索 |
| C. 微信公众号 | `mp.weixin.qq.com`（公众号：**i自然全媒体**） | 单篇文章标题+正文 | 单篇否；批量枚举受限 | ★★ 仅作补充 |
| D. 网络检索兜底 | 百度 / 各省厅网站 / 部网站转载 | 转载稿与线索 | 否 | ★★ 交叉核验用 |

**要点**：本项目的“山东周讯”把《中国自然资源报》列为来源却拿不到原文，根因是此前只试了 `iziran.com`（该域名已废）。正确域名是 **`iziran.net`**，而真正的取文库房是 **数字报的全文检索接口**。

## 二、通道 A：i自然官网（中国自然资源报社主办）

### 2.1 网站入口

- 首页：`https://www.iziran.net/index.html`
- 栏目页：`https://www.iziran.net/column.html?cid=<栏目ID>`
- 文章页：`https://www.iziran.net/news.html?aid=<fileID>`

网站是 Vue 单页，但**数据接口是公开 JSON**，可直接 HTTP 调用，无需浏览器渲染。

### 2.2 接口（无需登录）

```
栏目列表：GET https://api.iziran.net/api/getArticles?cid=<栏目ID>&rowNumber=0&lastFileID=0&pageNumber=<页>&pageSize=20&imgTop=0&orderby=&excids=1,2,3
单篇全文：GET https://api.iziran.net/api/getArticle?aid=<fileID>
子栏目：  GET https://api.iziran.net/api/getSubColumns?cid=<栏目ID>&type=2&order=desc
```

`getArticle` 返回字段：`fileID / title / subTitle / author / editor / source / publishTime / columnName / articleWordCount / content`（`content` 为完整 HTML 正文）。实测《湖北汉川：“天空地网”织密耕地保护网》返回正文 924 字，与官网页面一致。

## 三、通道 B：数字报（报纸电子版，最权威）

### 3.1 入口与页面结构

| 用途 | 地址 |
| --- | --- |
| 数字报首页 | `https://szb.iziran.net/` → 跳 `https://szb.iziran.net/bz/html/index.html` |
| 某日版面 | `…/bz/html/index.html?date=2026-09-15&pageIndex=1&cid=1` |
| 某篇文章 | `…/bz/html/content.html?date=<日期>&pageIndex=<版序>&pageId=<版UUID>&cid=1&articleId=<文章UUID>&articleIndex=<序号>` |
| 站内检索（人工） | `…/bz/html/search.html?formJson={"field":"all","keyword":"测绘","startDate":"","endDate":""}&cid=1` |
| 往期报纸 | `…/bz/html/archive.html?cid=1` |
| 可选日期清单 | `https://szb.iziran.net/xcms-pc/static/cache/bz1.json`（公开 JSON，列出全部出版日期） |

### 3.2 关键：先取匿名会话

数字报的数据接口要求登录态，但**支持匿名 IP 会话**，两步即可：

```http
GET https://szb.iziran.net/user/ipLogin?rd=<毫秒时间戳>&identity=<UUID>
    Cookie: identity=<同一个UUID>
```

返回 `{"success":true,"data":{"userId":"999999999",...}}` 即成功。之后所有请求都要带上：

```http
Cookie: identity=<UUID>
myIdentity: <同一个UUID>
Referer: https://szb.iziran.net/bz/html/index.html
SITE: iziran
X-Requested-With: XMLHttpRequest
```

缺 `myIdentity` 头会返回 `{"code":100,"message":"没登录"}`——这是之前尝试失败的关键点。

### 3.3 全文检索接口

```
POST https://szb.iziran.net/data/query
Content-Type: application/x-www-form-urlencoded

index=bz_page        # 版面索引：版次、版面大图、PDF 路径
index=bz_article     # 文章索引：标题、作者、版次、全文
query=<Elasticsearch DSL 的 JSON 字符串>
```

**按日期取版面（`bz_page`）**

```json
{"from":0,"size":999,
 "query":{"bool":{"must":[{"term":{"columns.id":1}},
                          {"term":{"bzDate_date_sore":"2026-09-15"}}]}},
 "sort":[{"pageIndex_int_sore":{"order":"asc"}}]}
```

**关键词全文检索（`bz_article`）**——站点自带做法是对 `text1..textN_fielddata` 拼接后做 `indexOf` 包含匹配：

```json
{"from":0,"size":20,
 "query":{"bool":{"must":[{"term":{"columns.id":1}},
                          {"range":{"bzDate_date_sore":{"gte":"2026-08-01","lte":"2026-09-15"}}},
                          {"bool":{"should":[
                             {"term":{"title_ngram_sore":"实景三维"}},
                             {"term":{"author_ngram_sore":"实景三维"}},
                             {"term":{"column_ngram_sore":"实景三维"}},
                             {"script":{"script":{"lang":"painless",
                               "inline":"if(doc['split_text_int_sore'].empty){return false;}int n=(int)doc['split_text_int_sore'].value;StringBuffer b=new StringBuffer();for(int x=1;x<=n;x++){String t='text'.concat(String.valueOf(x)).concat('_fielddata');if(null!=doc[t]){b.append(doc[t].value);}}return b.indexOf(params.a)!=-1;",
                               "params":{"a":"实景三维"}}}}]}}]}},
 "sort":[{"bzDate_date_sore":{"order":"desc"}}]}
```

实测：`实景三维` 在 2026-08-01～09-15 区间命中 **66 篇**，返回标题、作者、版次与正文。

### 3.4 常用字段

**`bz_article`（文章）**

| 字段 | 含义 |
| --- | --- |
| `title_ngram_sore` / `subtitle_ngram_sore` | 主题 / 副题 |
| `author_ngram_sore` | 作者（多作者连写） |
| `bzDate_date_sore` | 见报日期 |
| `pageNumber_sore` / `pageName_ngram_sore` / `pageIndex_sore` | 版次（如 `07`、`07版`） |
| `subtitle_ngram_sore`、`introTitle_ngram_sore` | 引题 / 副题 |
| `split_text_int_sore` + `text1..textN_fielddata` | **正文全文**（分片存放，N 由 `split_text_int_sore` 给出） |
| `text_nlp_sore` | 正文（分词版本，便于关键词高亮） |
| `points_sore` | 该文在版面大图上的坐标 |
| `pageId_no_analyzer_sore` / `bzId_no_analyzer_sore` | 版面 UUID / 期次 UUID |
| `bzIsbn_sore` | 报纸编号（1 号报为 `2108`） |

**`bz_page`（版面）**

| 字段 | 含义 | 拼接 |
| --- | --- | --- |
| `pdfFilePath_sore` | 整版 PDF 路径 | `https://szb.iziran.net/dataFile` + 路径（中文需 URL 编码） |
| `imgLFilePath_sore` | 整版高清大图 | 同上 |
| `imgSFilePath_sore` | 整版缩略图 | 同上 |
| `pageName_sore` / `pageNumber_sore` | 版名 / 版次 | — |
| `width_sore` / `height_sore` | 大图像素（实测 4353×6222） | — |

实测 PDF 直链可用：`https://szb.iziran.net/dataFile/batch/iziran/bz/20260105/中国自然资源报/20260915/2026091501.pdf` → HTTP 200，7.58 MB，`application/pdf`。

## 四、通道 C：微信公众号

### 4.1 实际情况

- 报社主号是 **“i自然全媒体”**（公众号简介即“中国自然资源报”），`gh_34a2c298c84b`，`__biz=MjM5NTk2MjY1Mw==`。
- **单篇文章链接公开可读**：`https://mp.weixin.qq.com/s?__biz=…&mid=…&idx=…&sn=…`，无需登录即可取到标题、公众号名与正文（实测《2026年〈中国自然资源报〉数字报来啦！》可正常解析）。
- **批量枚举受限**：
  - `mp/profile_ext?action=home`（历史消息列表）触发微信“验证”页，无法直连；
  - 搜狗微信搜索对该号无收录（返回“暂无相关官方认证订阅号”）。
- 因此公众号适合**按已知链接单篇抓取**，不适合作为全量入口。

### 4.2 可用的链接发现方式

1. 百度检索 `mp.weixin.qq.com 中国自然资源报/ i自然全媒体 <关键词>`，结果页会直接给出 `mp.weixin.qq.com/s?...` 链接；
2. 自然资源部网站「应用链接—微信」页 `https://www.mnr.gov.cn/wzxx/yy/wx/` 提供公众号矩阵入口；
3. 若后续需要批量取公众号，建议在微信客户端内翻取合辑页（参考本项目山东周讯的做法：`mp/appmsgalbum` + `album_id`），需要先拿到合辑 ID。

## 五、通道 D：网络检索兜底

- 各省自然资源厅网站普遍设「媒体聚焦/媒体报道」栏目并标注“来源：中国自然资源报”，可作交叉核验（如江苏厅 `zrzy.jiangsu.gov.cn/xwzx/mtsy/`）。
- 百度可检索到大量转载（澎湃、百家号、省级厅网站），但**刊期、版次、原文完整性均不如数字报**，仅作线索。
- 提示：`iziran.com`、`zrzyb.net`、`zrzyb.cn` 等域名均不可用，勿再尝试。

## 六、已落地的采集脚本

脚本：`2026年8-9月测绘动态资讯/99_脚本/20_zrzyb.py`（纯标准库，无需安装依赖）

```powershell
cd "<工作根 ToolRoot>\2026年8-9月测绘动态资讯"

# A. 官网：按栏目取列表（cid 可用中文名）
python 99_脚本/20_zrzyb.py a-list --cid 测绘 --pages 2 --page-size 20
python 99_脚本/20_zrzyb.py a-list --cid 要闻 --pages 1 --fulltext   # 连正文一起抓

# A. 官网：单篇全文
python 99_脚本/20_zrzyb.py a-article --aid 5494600

# B. 数字报：某日全部版面 + PDF 直链
python 99_脚本/20_zrzyb.py b-pages --date 2026-09-15

# B. 数字报：全文检索（可限定日期区间）
python 99_脚本/20_zrzyb.py b-search --kw 实景三维 --start 2026-08-01 --end 2026-09-15 --size 50
python 99_脚本/20_zrzyb.py b-search --kw 测绘 --field title --size 20

# B. 数字报：按 ES _id 取单篇（含全文）
python 99_脚本/20_zrzyb.py b-article --id <b-search 输出里的 esId>

# C. 公众号：单篇抽取
python 99_脚本/20_zrzyb.py c-wechat --url "https://mp.weixin.qq.com/s?__biz=MjM5NTk2MjY1Mw==&mid=..."
```

输出统一落在 `_raw/zrzyb/*.json`。

## 八、注意事项

1. **访问频率**：接口无显式限流，但仍建议 1～2 秒间隔、并发不超过 2，避免被 WAF 拦截。
2. **会话有效期**：`ipLogin` 匿名会话有有效期，长时间任务建议失败即重新登录。
3. **正文口径**：数字报全文为“见报稿”，i自然官网为“网络稿”，两者可能略有出入；正式引用建议以数字报为准并标注版次。
4. **版权**：抓取内容仅用于内部资讯汇编与选题参考，转载/出版需获得中国自然资源报社授权。
