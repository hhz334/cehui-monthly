## 三、通道 A：省政务统一检索接口（最推荐）

浙江全省政务网站共用一套检索服务，**返回 JSON 且自带正文**，这是查询效率最高的方式。

### 3.1 请求

```http
GET https://search.zj.gov.cn/api-gateway/jpaas-jsearch-web-server/interface/search/app/info
    ?q=测绘
    &serviceId=YcTOd1ftgC5dxzJ8RhCBN
    &cateid=VYyQDa265Tnj5A7jf9q6k      # 动态信息
    &p=1                                # 页码
    &pg=20                              # 每页条数
    &sortType=2
    &websiteid=330000000000             # 省政府平台
    &_cus_eq_webid=1568                 # 1568 = 浙江省自然资源厅
```

`_cus_eq_webid` 是**站点过滤器**，填 `1568` 就只返回浙江厅的内容；留空则检索全省政务网站（可用来找其他单位）。

### 3.2 分类 cateid

| 分类 | cateid | 分类 | cateid |
| --- | --- | --- | --- |
| 全部 | `6N89tbnrVTYIQK5jt7q3T` | 公告公示 | `E6OnRo9SrojDOf5JGpc7x` |
| **动态信息** | `VYyQDa265Tnj5A7jf9q6k` | 信息公开 | `pxqXRJ8GOBibTdpvrmvYz` |
| 法规文件 | `RD2hFhHjNN8CSHjKEtSUx` | 政民互动 | `CnN4JKUa9mrCbdJzLAXLt` |
| 机构人事 | `JcWYdyk9h9TDZMUT63ts9` | 数据开放 | `jPP8PPL77kmFDxqlxYNY1` |
| 政务专题 | `26B9ATqNIxOTdzUrTLfPg` | 其他 | `ROJC4StewZSmYa3mLLPYs` |

可选参数：`begin` / `end`（配合 `timetype=timeqb` 限定日期区间）。

### 3.3 返回结构（关键字段）

```
data.appSearchResultBeanList[0].mapSearchResult
  ├─ total                    命中总数
  └─ items[].data
       ├─ title_h             标题（含高亮标签）
       ├─ url                 文章地址
       ├─ webname             站点名（如"浙江省自然资源厅"）
       ├─ tag                 栏目（如"工作动态"）
       ├─ module              模块（如"资质审批结果"）
       ├─ column              栏目 ID
       ├─ author / keyword    作者 / 关键词
       ├─ checktime           时间戳
       └─ vc_content          正文 HTML（可直接取用）
```

## 四、通道 B：栏目列表接口（解决"JS 列表抓不到"）

### 4.1 原理

栏目页 `/col/col<ID>/index.html` 的正文区其实是一个占位 `<script>`，真正内容由 `unitbuild.js` 调用接口填充：

```html
<script ... url="/api-gateway/jpaas-publish-server/front/page/build/unit"
  queryData="{'parseType':'bulidstatic','webId':'1568','tplSetId':'U7bvrVv0UTSYUGzg0A38n',
              'pageType':'column','tagId':'土地类列表','editType':'null','pageId':'1229767838'}">
```

**做法**：先抓栏目页取出 `queryData`（`tplSetId`、`tagId` 因栏目而异，不要写死），再带上分页参数请求接口。

### 4.2 请求

```http
GET https://zrzyt.zj.gov.cn/api-gateway/jpaas-publish-server/front/page/build/unit
    ?parseType=bulidstatic
    &webId=1568
    &tplSetId=U7bvrVv0UTSYUGzg0A38n
    &pageType=column
    &tagId=土地类列表
    &editType=null
    &pageId=1229767838
    &paramJson={"pageNo":1,"pageSize":20,"search":""}
```

返回 JSON：`data.html` 是列表片段，结构为

```html
<li class="cf">
  <a class="fl" href="/col/col1229767838/art/2026/art_64fe85d7a0884d58b68aca79e7082154.html"><i></i>标题</a>
  <span class="fr">2026-09-10</span>
</li>
```

注意：**列表里的标题会被截断**（显示省略号），需要完整标题请回文章页取 `<title>`。

### 4.3 实测

| 栏目 | 结果 |
| --- | --- |
| 测绘成果使用审批（1229767838） | 每页正常返回，分页有效 |
| 工作动态（1289955） | 正常，《浙江省基础测绘办法》等测绘稿在此 |
| 测绘地理信息（1633746） | **无列表单元**，确认是服务导航页 |

## 六、通道 D：浙江省测绘科学技术研究院公众号

### 6.1 公众号信息

| 项目 | 值 |
| --- | --- |

### 6.2 取文三步（与泰伯网同一套链路）

```http
# 1) 检索（type=2 表示搜文章）
GET https://weixin.sogou.com/weixin?type=2&query=浙江省测绘科学技术研究院&ie=utf8&page=1

# 2) 还原真实地址：取返回页里 url += '...' 的片段按顺序拼接
GET https://weixin.sogou.com/link?url=dn9a_...
→ https://mp.weixin.qq.com/s?src=11&timestamp=…&signature=…&new=1

# 3) 抓正文：解析 var msg_title / id="js_name" / var biz / id="js_content"
GET <上一步得到的地址>
```

实测成功取到《共青团浙江省测绘科学技术研究院第一次代表大会顺利召开》，公众号名"浙江省测绘科学技术研究院"，`__biz=MzkzMTAxOTQyMg==`，正文 646 字。

### 6.3 必须知道的限制：搜狗对该号索引稀疏

- 搜狗**账号搜索**（`type=1`）对"浙江省测绘科学技术研究院"返回"暂无相关的官方认证订阅号"；
- **文章搜索**（`type=2`）能搜到，但命中很少，且明显滞后。

实测不同关键词的命中（仅统计该公众号名下）：

| 检索词 | 总结果 | 其中本院公众号 |
| --- | --- | --- |
| 浙江省测绘科学技术研究院 | 10 | 2 |
| 省测绘科学技术研究院 | 10 | 2 |
| 浙江测绘院 / 浙江省测绘院 | 10 | 0 |

**应对办法**：用多个关键词（院名全称、简称、"省测绘科学技术研究院"）分别检索后合并去重，并按返回结果里的 `all-time-y2`（公众号名）字段过滤；结果里出现的多半是 2020—2024 年的文章，说明近期内容收录不全。

### 6.4 补充渠道

研究院的**招聘、公示类信息**会发在浙江厅网站（实测统一检索命中 27 条，如"公开招聘编外人员的公告""拟聘人员公示"），可用通道 A 直接获取；**业务与党建动态**才主要靠公众号。

## 九、注意事项

1. **优先用统一检索**：一次请求同时拿到标题、链接、栏目、时间和正文，比逐栏目翻列表高效得多。
2. **站点过滤别写错**：`_cus_eq_webid=1568` 才是省自然资源厅；要查其他单位时留空或换 ID。
3. **列表标题会被截断**，正式引用前务必回文章页取完整标题。
4. **公众号链路有反爬**：搜狗需先建立会话（`SNUID`/`SUID` cookie），建议每页间隔 ≥5 秒；还原出的 `mp.weixin.qq.com/s?src=11&signature=…` 是**时效链接**，需即取即用。
5. **访问频率**：浙江厅接口无显式限流，仍建议 1～2 秒/次。
6. **版权**：抓取内容仅用于内部资讯汇编与选题参考，对外转载需获授权。
