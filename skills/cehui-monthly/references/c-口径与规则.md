# 口径与规则（对外可执行的版本）

完整版在 `<工作根 ToolRoot>\00_测绘动态资讯采集口径.md` 与 `..\01_作业流程（SOP）.md`；
本文件是执行时最常用的判定与阈值，两者冲突时以完整版为准并同步修正。

## 三板块

| 板块 | 收什么 |
| --- | --- |
| 政策类 | 国家与地方的政策、规划、标准、办法（国家层面公文并入） |
| 技术应用类 | 工程落地、业务应用、产业动态，**以及经验做法稿**（原“媒体动态类”内容） |
| 科技前沿类 | 技术研发、算法模型、系统成果、学术交流 |

## 规则编号

- **R1 自动排除**：培训/讲座/讲堂/竞赛/练兵、签约/调研/座谈/走访、验收/评审、地市级（市局/县局）、
  非部级会议、程序性文件与标准征求意见、基金指南、宣传科普版图、视频/音频/图集、期次页、福建本地内容。
- **R2 人工精选**：部级重大成果取舍；同事件只留一条；应急测绘同类只留最强一条；部属单位内部事务性动态不收。
- **R3 归类修正**：国家层面成果发布与服务落地归技术应用类；经验做法稿归技术应用类，不留科技前沿类。
- **R4 排序**：板块 → 层级（部级→行业与官媒→外省）→ 业务中心度（见下）→ 发布日期倒序；
  优先级 A/B/C 只作字段；骨架保序，补充条目插到第一条排序键大于它的条目之前。
- **R5 来源分层**：国家级（自然资源部）与省级（浙江自然资源等）公众号可作来源；地市级公众号仅作线索；
  周讯等转载汇编号只作线索。
- **R6 链接**：一条可有主链接（官方原文）＋延伸链接（图解等）；主链接必须是原发布方。
- **R7 批注回灌**：收到批注版 → `29` 解析 → `31` 出选目 → `30` 回归；规则与领导判断冲突时以领导版为准并回写规则。
- **R8 前沿类门槛**：科技前沿类只收有技术实质的内容（方法/指标/模型/成果）；产业评论、会议召开不收。
  论文与国际奖项例外已取消，**国际内容一律不收**。

## 业务中心度（R4 第三键，依本中心党组半年工作情况汇报章节序）

实景三维建设 → 测绘基准服务 → 测绘地理信息公共服务 → 测绘科技创新与关键技术攻关 → 应急测绘保障 →
自然资源调查监测技术支撑 → 自然资源执法监管技术支撑 → 测绘行业管理与技术服务 →
地理信息数据安全与保密 → 卫星遥感与多源数据融合应用。

## 量化阈值（改代码必须同步改文档）

| 阈值 | 取值 | 代码位置 |
| --- | --- | --- |
| 正文最小字数 | 200 字（不足标“待补”，不进成册） | `25_verify_source_entity.py` `MIN_TEXT` |
| 标题要素覆盖率 | ≥0.7 | 同上 `MIN_COVER` |
| 单来源初筛上限 | 每来源 6 条 | `24_auto_shortlist.py` `MAX_PER_SOURCE` |
| 同事件合并 | 标题相似度 ≥0.85 | `25_verify_source_entity.py` `similar()` |
| 正文垃圾判定 | 命中 ≥2 个垃圾特征，或 1 个且正文 <800 字 | `sources_whitelist.py` `is_junk_text()` |
| 国际奖项回溯 | 已取消（国际内容一律不收） | `sources_whitelist.py` |

## 正文质量

- 整页导航/前端模板文本不算正文；图片页、视频页按抓取失败处理。
- 摘要必须是实质内容，禁止“××报道：……正文见源链接”这类模板句。
- **段落换行必须保留**：抓取按块级标签换行（含公众号 `<section>`）；成刊一行即一段。

## 排除与例外

- 不收：国际、党建/巡视/廉政/青年工会活动、科普物料与地市级宣传、财务预决算与采购公告、期次页与连载栏目页、
  视频/音频/图集/海报、推广宣传稿、日常调研培训、福建本地内容、来源不可核实的条目。
- 测绘法宣传日暨国家版图意识宣传周：只收部级专题稿件与省级做法成效报道（人工指定采纳），海报/短视频/活动集锦不收；
  板块归属技术应用类。
