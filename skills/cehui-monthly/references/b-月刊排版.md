# 阶段B：月刊排版

## 链路

```
期次目录\99_脚本\catalog_selection_final.json      （阶段A 的定稿选目）
        ↓ 编制排版\_build_monthly_template.py       （可选）从《政策要情》参考件重建三栏目模板
   编制排版\测绘动态月刊_模板.docx / .dotx
        ↓ 编制排版\_make_issue.py                   （克隆版式 → 填内容 → 渲染 → 回读页码 → 收敛）
   编制排版\测绘动态工作_<期号>.docx
        ↓ render_docx.py                            （导出 PDF 与逐页 PNG）
   编制排版\测绘动态工作_<期号>.pdf + 月刊预览\
```

入口：`scripts\run_monthly_issue.ps1 -PeriodDir <期次目录> [-RebuildTemplate] [-Forward]`。

## 版式不变量（2026-09-17 领导确认版）

- **封面**：红字刊名“测绘地理信息月刊”，方正小标宋简体、36pt、颜色 C00000、居中文本框（沿用《政策要情》版式）。
  文本框所在 run 不能被删（脚本里用 `keep_drawing=True` 保护），封面不再另插黑色刊名行。
- **正文页眉**：栏目名居中＋底边框；栏名上方留一个“同为底边框＋居中”的空段落（页眉整体下移一行）；
  中英文字体统一黑体（`_set_latin_font.py` 默认不改页眉页脚，需要时传 `include_headers=True`）。
- **三栏目**：政策类／技术应用类／科技前沿类；模板共 4 节（封面＋3 栏目），`_build_monthly_issue.py` 断言分节符为 3。
- **正文**：全文（不节选）＋**文末原文链接**；**一行即一段**（`body_paragraphs()` 只对 >800 字的超长行按句号断开）。
- **正文三级格式**（依《政策要情》第 100 期核定，模板与成刊一致）：一级标题 `一、`→黑体小四（12pt）不加粗；
  二级标题 `（一）`→楷体_GB2312 小四加粗；正文小标题 `1.`→仿宋_GB2312 小四加粗（仅“标签：”部分加粗）；
  正文→仿宋_GB2312 小四不加粗；首行缩进 2 字符。`_build_monthly_issue.py` 按行首模式自动分级，
  模板里的样板占位符为`【一级标题】／【二级标题】／【正文小标题】`，缺样板时自动退回正文格式。
- **目录页**：期号行（日期／第 N 期／编制单位）＋三栏目条目，页码由第二轮渲染回读写入，迭代至收敛。

## 版式体检（出刊后必做）

1. 页数、`来源：` 行数、`原文链接：` 数三项比对：后两者应等于目录条数。
2. 封面第 1 行是红字刊名（size>30、色值≈C00000），第 2 行是期号行。
3. 任取一个正文页：页眉栏目名 top≈59、装饰线 top≈71（A4×96dpi 渲染坐标），正文首行缩进 304800 EMU。
4. 全文检索不得出现“媒体动态类”；目录页码与正文实际页码一致；无空节、无空白页。
5. 若某栏目条数为 0，模板该节会留空——需在交付说明中说明，不要伪造条目。

## 常见问题

- **页码不收敛**：`_make_issue.py` 最多迭代 5 轮；仍不收敛时多半是目录条目文字过长换了行，缩短标题或减少每栏目条数。
- **封面红字丢失**：说明改文案时删掉了文本框 run（`set_text(..., keep_drawing=True)` 缺失）。
- **页眉字体被改成 Times New Roman**：`_set_latin_font.py` 被用 `include_headers=True` 调用过，重跑模板即可恢复。
- **正式文件被占用无法写入**：关闭 WPS/Word 预览后重跑；脚本会跳过被占用文件并提示。
