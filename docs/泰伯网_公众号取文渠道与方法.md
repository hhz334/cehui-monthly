# 泰伯网 微信公众号取文渠道与方法（实测版）

> 实测时间：2026-09-15
> 实测网络：本机直连（无需代理、无需登录）
> 结论：**公众号单篇可完整取到，但"按公众号批量枚举"没有官方入口；实际采集应"官网为主 + 搜狗微信为辅"。**

---

## 一、先确认对象身份

| 项目 | 值 |

| 旧域名 | `www.3snews.net` —— **已失效**：任意路径都返回首页外壳，不要再用 |
| 图片 CDN | `imgcdn.3snews.net` |
| 微信公众号 | **泰伯网**（`__biz=MjM5NTg1MzcyMQ==`） |
| 微信号 | `news_3snews` |

**关键判断：泰伯网官网与公众号是同一编辑部的同源内容**——同一篇《泰伯早报》《独家》《深度》在两处都有，官网更新更快、结构更规整。因此公众号取文的最优解不是"抓公众号"，而是"抓官网 + 用搜狗微信补公众号独有内容"。

## 三、通道 A：泰伯网官网（最稳）

### 3.1 列表与检索（AJAX 片段接口）

列表是"点击加载更多"式分页，**必须带 `X-Requested-With: XMLHttpRequest` 头**，否则返回整页 HTML：

```http
GET https://www.taibo.cn/info?page=2
X-Requested-With: XMLHttpRequest
Referer: https://www.taibo.cn/info
→ 返回 HTML 片段，每页 10 条 <div class="media article-item">
```

| 用途 | 地址 |
| --- | --- |
| 资讯频道 | `https://www.taibo.cn/info?page=N` |
| 泰伯早报 | `https://www.taibo.cn/info/zaobao?page=N` |
| 站内检索 | `https://www.taibo.cn/search?q=<关键词>&page=N` |

片段里每条含：`href="/p/<id>"`、标题（`class="item-title"`）、摘要（`<p>`）、时间（`<time datetime="...">`）、标签（`/search?q=` 链接）。

### 3.2 单篇正文

```http
GET https://www.taibo.cn/p/99719
```

可稳定解析：`og:title`、`og:description`、`keywords`、`article-content`（正文）、`article-author-date`（作者/栏目/时间）。

### 3.3 全量回溯

```http
GET https://www.taibo.cn/sitemap.xml
```

实测 436 KB、2740 个 `<loc>`，其中约 2000 条是 `http://www.taibo.cn/p/<id>`，按 id 递增，**可用于一次性拿到全部文章地址**。

## 四、通道 C：微信公众号（搜狗微信）

### 4.1 为什么绕道搜狗

微信官方对公众号历史消息（`mp/profile_ext`）有反爬验证，无客户端无法枚举。**搜狗微信是目前唯一可用的免费检索入口**，对"泰伯网"检索到约 **3011 条**相关文章。

### 4.2 三步取文

**第一步：检索（`type=2` 表示搜文章）**

```http
GET https://weixin.sogou.com/weixin?type=2&query=%E6%B3%B0%E4%BC%AF%E7%BD%91&ie=utf8&page=2
```

每页 10 条，解析 `<div class="txt-box">`：

| 元素 | 含义 |
| --- | --- |
| `href="/link?url=..."` | 跳转链接（不是真实地址） |
| `id="sogou_vr_11002601_title_N"` | 标题 |
| `class="txt-info"` | 摘要 |
| `class="all-time-y2"` | **公众号名**（用它过滤出 `泰伯网`） |
| `timeConvert('1789436905')` | 发布时间戳 |

**第二步：还原真实地址**

```http
GET https://weixin.sogou.com/link?url=<第一步的 url>
```

返回的是一段 JS，把 `url += '...'` 的片段**按顺序拼接**（并去掉 `@`），即得：

```
https://mp.weixin.qq.com/s?src=11&timestamp=1789437013&ver=6967&signature=5Kdp...&new=1
```

**第三步：抓正文**

该地址可直接 HTTP 获取（约 3.5 MB HTML），解析 `var msg_title`、`id="js_name"`（公众号名）、`var biz`、`id="js_content"`（正文）。

> 实测：成功取到《深度 | 马斯克宣布：人类模型+世界模型》，公众号名“泰伯网”，`biz=MjM5NTg1MzcyMQ==`，正文 599 字。

### 4.3 两个必须知道的坑

1. **必须先建立会话**：直接请求 `/link?url=` 会拿不到目标地址；需先访问一次搜索页拿到 `SNUID`/`SUID` cookie。
2. **有反爬验证码**：连续快速翻页会触发验证码页（`antispider`）。建议**每页间隔 ≥5 秒、单次会话 ≤10 页**，触发后换 IP 或隔一段时间再试。
3. **索引有滞后**：当天的《泰伯早报》在搜狗检索不到（实测 9月15日早报无结果），需次日才收录——所以**日报类内容必须走官网**。

### 4.4 搜狗是"关键词维度"，不是"公众号维度"

搜狗账号搜索（`type=1`）对"泰伯网"返回"暂无相关官方认证订阅号"，**无法按公众号枚举**。可行做法：用主题关键词检索（如"低空经济""时空智能"），再用返回的 `all-time-y2` 字段过滤出 `泰伯网`。

## 五、重要限制：深度稿有会员墙（官网和公众号都有）

这是本次实测最值得注意的一点。**免费内容与付费内容的边界：**

| 文章类型 | 官网 | 公众号 | 实测证据 |
| --- | --- | --- | --- |
| 泰伯早报（日更） | ✅ 全文免费 | ✅ 全文免费 | 《泰伯早报｜9月15日》官网 2283 字，无付费标记 |
| 普通资讯 / 短稿独家 | ✅ 全文 | ✅ 全文 | 《独家｜湖北国资跨省抢投知名卫星公司》官网 772 字、公众号 643 字，均为完整短稿 |
| **深度 / 精选稿** | ❌ 截断 | ❌ 截断 | 《深度｜马斯克宣布：人类模型+世界模型》官网正文至 621 字即被截断；公众号版同样在 599 字处写“**…… 全文3639字。点击左下方“阅读原文”，订阅泰伯网Pro会员即可畅读全文**” |

**结论**：深度稿要全文必须订阅泰伯网 Pro 会员，公众号和官网**都不能绕开**。免费渠道能稳定拿到的是早报、动态资讯和短稿独家。

## 六、通道 D：网络检索兜底

- 泰伯网文章被多家转载（搜狐号、百家号、省级协会网站等），可用百度检索标题定位；
- `imgcdn.3snews.net` 图片可直连，做图文归档时可直接下载；
- 另有付费产品「泰伯数据通」`data.taibo.cn` 与智库 `tiu.taibo.cn`，不属免费取文范围。

## 七、已落地的采集脚本

脚本：`2026年8-9月测绘动态资讯/99_脚本/21_taibo.py`（纯标准库，无需安装依赖）

```powershell
cd "<工作根 ToolRoot>\2026年8-9月测绘动态资讯"

# A. 官网：资讯列表 / 早报
python 99_脚本/21_taibo.py a-list    --page 1
python 99_脚本/21_taibo.py a-zaobao  --page 1

# A. 官网：站内检索（可翻多页）
python 99_脚本/21_taibo.py a-search  --q 低空经济 --pages 3

# A. 官网：单篇正文（自动标记是否会员墙）
python 99_脚本/21_taibo.py a-article --id 99719

# C. 公众号：搜狗微信检索
python 99_脚本/21_taibo.py b-search  --q 泰伯网 --pages 2 --sleep 6

# C. 公众号：还原链接 → 抓正文
python 99_脚本/21_taibo.py b-resolve --link "/link?url=dn9a_..."
python 99_脚本/21_taibo.py b-article --url "https://mp.weixin.qq.com/s?src=11&..."
```

输出统一落在 `_raw/taibo/*.json`；官网单篇结果带 `memberOnly` 字段，便于下游区分是否需要会员。

## 九、注意事项

1. **优先官网**：更新更快、无反爬、结构稳定；搜狗微信仅用于补漏。
2. **控制频率**：官网建议 1～2 秒/次；搜狗微信 ≥5 秒/页，避免触发验证码。
3. **链接时效**：搜狗还原出的 `mp.weixin.qq.com/s?src=11&signature=...` 带时效签名，**需即取即用**；若要长期保存，请记录标题+公众号+日期作为定位键。
4. **版权**：泰伯网内容用于内部资讯汇编与选题参考无碍；深度稿受会员协议约束，**不要绕过付费墙**，对外转载需获授权。
