# 阶段B：月刊排版

## 链路

```
期次目录\99_脚本\catalog_selection_final.json      （阶段A 的定稿选目）
        ↓ 编制排版\_build_monthly_template.py       （可选）从《政策要情》参考件重建三栏目模板
   编制排版\测绘动态月刊_模板.docx / .dotx
        ↓ 编制排版\_make_issue.py                   （克隆版式 → 填内容 → 渲染 → 回读页码 → 收敛）
   编制排版\测绘动态工作_<期号>.docx
        ↓ render_docx.py                            （导出 PDF 与逐页 PNG）
   编制排版\测绘动态工作_<期号>.pdf + 月刊预览\
```

入口：`scripts\run_monthly_issue.ps1 -PeriodDir <期次目录> [-RebuildTemplate] [-Forward]`。

## 版式不变量（2026-09-17 领导确认版）

- **封面**：红字刊名“测绘地理信息月刊”，方正小标宋简体、36pt、颜色 C00000、居中文本框（沿用《政策要情》版式）。
  文本框所在 run 不能被删（脚本里用 `keep_drawing=True` 保护），封面不再另插黑色刊名行。
- **正文页眉**：栏目名居中＋底边框；栏名上方留一个“同为底边框＋居中”的空段落（页眉整体下移一行）；
  中英文字体统一黑体（`_set_latin_font.py` 默认不改页眉页脚，需要时传 `include_headers=True`）。
- **三栏目**：政策法规／技术应用类／科技前沿类；模板共 4 节（封面＋3 栏目），`_build_monthly_issue.py` 断言分节符为 3。
- **正文**：全文（不节选）＋**文末原文链接**；**一行即一段**（`body_paragraphs()` 只对 >800 字的超长行按句号断开）。
- **正文三级格式**（依《政策要情》第 100 期核定，模板与成刊一致）：一级标题 `一、`→黑体小四（12pt）不加粗；
  二级标题 `（一）`→楷体_GB2312 小四加粗；正文小标题 `1.`→仿宋_GB2312 小四加粗（仅“标签：”部分加粗）；
  正文→仿宋_GB2312 小四不加粗；首行缩进 2 字符。`_build_monthly_issue.py` 按行首模式自动分级，
  模板里的样板占位符为`【一级标题】／【二级标题】／【正文小标题】`，缺样板时自动退回正文格式。
- **标题与正文同段**：如“（一）加快构建国家数字空间基准。一是……三是……”，只有到第一个句号为止的标题部分
  用标题格式，其后内容按正文（仿宋_GB2312 小四不加粗）排版；`一、` 与 `（一）` 两级同样处理。
- **模板样例＝真实示例**（2026-09-17 调整）：模板三个栏目里放的是与成刊一致的示例条目
  （`【省份】标题` → `来源：单位` → 正文 → `一、` → `（一）` → `1.标签：` → `原文链接：https://…`），
  不再使用“【正文段落：做法、成效与评析。】”这类占位描述；出刊脚本**按格式（字体＋字号＋加粗）识别样板**，
  因此模板里换示例文字不影响成刊。改模板后务必用一条真实选目跑一次出刊，确认打印出
  “样板（按格式识别）：来源行✓ 正文✓ 一级✓ 二级✓ 小标题✓”。
- **目录页**：期号行（日期／第 N 期／编制单位）＋三栏目条目，页码由第二轮渲染回读写入，迭代至收敛。

## 版式体检（出刊后必做）

1. 页数、`来源：` 行数、`原文链接：` 数三项比对：后两者应等于目录条数。
2. 封面第 1 行是红字刊名（size>30、色值≈C00000），第 2 行是期号行。
3. 任取一个正文页：页眉栏目名 top≈59、装饰线 top≈71（A4×96dpi 渲染坐标），正文首行缩进 304800 EMU。
4. 全文检索不得出现“媒体动态类”；目录页码与正文实际页码一致；无空节、无空白页。
5. 若某栏目条数为 0，模板该节会留空——需在交付说明中说明，不要伪造条目。
6. **文本核校（2026-09-17 增补，人工审核反馈）**：出刊后必须再过一遍文字，`run_monthly_issue.ps1` 会自动执行——

```powershell
python 99_脚本\27_text_qa.py --doc "<成稿.docx>" --out "<期次目录>\_备查\文本体例检查.md"
python 99_脚本\33_fix_docx_text.py "<成稿.docx>" -o "<成稿>_核校版.docx" --report "<期次目录>\_备查\成稿空格核校.md"
```

   - `27` 逐条给“空格问题／体例问题／原文有而成稿无／成稿有而原文无”。后两类要逐条给结论：
     署名、图片说明、`01/02/03` 小节序号、页面提示属人工有意删除；其余按漏字补回。
   - `33` 只改 `w:t` 文本节点，清特殊空白与多余空格、汉字间半角标点转全角；保留法条标题、引号内标语、
     页脚“— 1 —”与目录制表位。
   - 复核口径：核校版“汉字与字母/数字之间空格 0、特殊空白仅剩页眉 `\u3000`、引号书名号括号全部配对”。
   - **文末“原文链接：”是硬要求**（委托人明确要保留）；若人工审核版把它删了，先确认再改，不要默认跟随。
   - **已定稿（2026-09-17）**：领导审核版口径为准——**正文不排“原文链接”行**（链接只留在 `00_资讯目录` 与 `02_原文` 归档），
     **文末署名统一删除**。两者都由 `_build_monthly_issue.py` 执行，`render_and_check.py` 校验“原文链接 0 行”。
     若要恢复排印原文链接，设 `CEHUI_SOURCE_LINK=1` 后重跑阶段B。
7. **目录跳转与页码（2026-09-17 增补）**：成刊定稿后跑 `34_add_toc_links.py`（`run_monthly_issue.ps1` 已内置，
   就地执行）。

8. **每篇文章另起一页（R12，2026-09-17 定）**：

```powershell
python 99_脚本\38_page_break_per_article.py "<成刊.docx>"      # 就地补“段前分页”，已生成的成刊用这个
```

   - 新刊由 `_build_monthly_issue.py` 直接给标题段设 `pageBreakBefore`；**板块首条不设**（分节符已另页），否则多出空白页。
   - `38` 在设分页的同时删除标题前紧邻的空段落（最多 10 个）——空段被顶到新页会变成只有页眉页脚的空白页。
   - 验收：每个 `【省份】标题` 都出现在某页的第一行；`render_and_check.py` 的“无空白页”为 0 个。

```powershell
python 99_脚本\34_add_toc_links.py "<成刊.docx>" -o "<成刊.docx>"
```

   - 每条正文标题（`【省份】标题`）打 `toc_NN` 书签，目录条目文字包成 `HYPERLINK \l "toc_NN" \h` **域**，制表位与页码留在域之外。
   - **必须用域写法**（`--style field`，默认）：Word 原生 `w:hyperlink w:anchor` 在 WPS 里会被当作外部文件，
     点击提示“无法打开指定文件”（2026-09-17 用户实测）。域写法 Word/WPS 都认，导出 PDF 后变成 GoTo 注释，同样可点。
   - 验收：在 **WPS 里点 3 条**目录确认能跳；再导出 PDF 检查内部链接数＝条目数。
   - **页码按页脚“— N —”回填**，不按 PDF 物理页序；重排、加页或换模板后必须重跑（会把 45→46、48→49 这类错位改过来）。
   - 页码在 docx 里常被拆成多个 run（`24` = `2` + `4`），改写时要收全 tab 之后的全部 run，否则会出现 `111` 这类叠加错误。
   - 自检：目录条目数＝超链接数＝书签数；抽 3 条比对“目录页码＝目标页页脚页码”。

9. **页脚页码缓存（2026-09-17 用户实测）**：页脚是 `PAGE \* MERGEFORMAT` 域，域里保存着**上次排版的缓存值**
   （本刊模板自带 1／42／60）。Word/LibreOffice 打开会重算，**WPS 默认按缓存显示**，于是页脚页码与目录对不上。

```powershell
python 99_脚本\39_fix_footer_page_cache.py "<成刊.docx>"      # 阶段B 已内置，出刊后自动跑
```

   - 脚本按实际分页把每节首页的缓存值写成正确数字，并在 `word/settings.xml` 写入 `<w:updateFields w:val="true"/>`。
   - 页眉首栏名可能是“政策法规”（四个字）或“政策法规类”，匹配分节时两种都要认，否则映射会整体错位。
   - 验收：docx 里各页脚部件缓存值＝该节首页页脚页码；用 WPS 打开点一下页码确认。

10. **页脚对齐（2026-09-17 用户反馈“页脚歪了”）**：参考件《政策要情》的页脚文本框虽然水平居中，但**框内段落是左对齐**，
    页码落在页面中心偏左约 1.8cm；各分节 `w:pgMar/@w:footer` 也不一致（1247 / 992 twips），页码高差约 13pt。

```powershell
python 99_脚本\40_fix_footer_layout.py "<成刊.docx>"     # 阶段B 已内置；重建模板时也自动跑
```

   - 处理：①页脚文本框内段落加 `w:jc=center` 并去掉遗留制表位；②各分节页脚距离统一 1247 twips。
   - 验收：渲染后页脚“— N —”的水平中心＝页面中心（±1pt），各板块距页底一致（58.6pt）。

11. **字体（2026-09-17 用户反馈“导出的 pdf 字体丢失”）**：成刊要求
    `仿宋_GB2312`（正文）、`楷体_GB2312`（二级标题、来源行）、`黑体`（一级标题）、`方正小标宋简体`（刊名、条目标题）。
    注意：系统自带的“楷体/KaiTi（simkai.ttf）”**不是** `楷体_GB2312`，缺它时 LibreOffice 会把二级标题顶替成微软雅黑。

```powershell
python 99_脚本\41_export_pdf.py "<成刊.docx>" -o "<成刊.pdf>"   # 阶段B 已内置，导出前核对字体
```

   - 缺字体时脚本明确报警，**默认不替换字体名**；确需临时顶替用 `--allow-substitute --map 楷体_GB2312=楷体`。
   - 装字体：把 `楷体_GB2312.ttf` 放到 `%LOCALAPPDATA%\Microsoft\Windows\Fonts\`，写
     `HKCU\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts`，再 `AddFontResourceW` + 广播 `WM_FONTCHANGE`，
     否则本机已启动的 LibreOffice 仍看不到新字体。
   - 验收：`pdffonts`/脚本列出的 PDF 字体里应出现 `楷体_GB2312`（子集名常见 `KaiTi_GB2312`），且没有 `MicrosoftYaHei`。

## 常见问题

- **页码不收敛**：`_make_issue.py` 最多迭代 5 轮；仍不收敛时多半是目录条目文字过长换了行，缩短标题或减少每栏目条数。
- **封面红字丢失**：说明改文案时删掉了文本框 run（`set_text(..., keep_drawing=True)` 缺失）。
- **页眉字体被改成 Times New Roman**：`_set_latin_font.py` 被用 `include_headers=True` 调用过，重跑模板即可恢复。
- **正式文件被占用无法写入**：关闭 WPS/Word 预览后重跑；脚本会跳过被占用文件并提示。
