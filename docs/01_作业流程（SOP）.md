> 适用：福建省测绘地理信息发展中心《测绘动态工作（测绘地理信息月刊）》
> 版本：2026-09-17（板块改为三个，取消“媒体动态类”；论文与国际奖项例外取消；本期按领导终稿 16 条出刊）
> 配套文件：口径《00_测绘动态资讯采集口径.md》、来源《2026年8-9月测绘动态资讯/01_来源清单与采集方法.md》、三份专用通道方法文档

## 一、总览

**一句话链路**：设置期次与窗口 → 官网采集 → 专用通道采集 → 周讯对标（只作线索）→ 自动初筛 → 三板块重建与业务条线打标 → 来源实体校验与原文复检 → 成稿 → 多方式核实 → 交付。

**技能化入口（2026-09-17 起）**：本流程已封装为技能 `cehui-monthly`（`~/.codex/skills/cehui-monthly\`），
分两块执行，日常不必手敲脚本：

> 对外公开仓库：<https://github.com/hhz334/cehui-monthly>（含技能、工具链与口径文档，可整包下载或 `git clone`；
> 发布版已把本机路径改为 `CEHUI_TOOL_ROOT` 配置，不含期次数据）。

```powershell
# 阶段A 初稿目录生成（采集→初筛→批注回灌→核验→目录与原文归档→Word 交付件→自检）
powershell -File "~/.codex/skills/cehui-monthly\scripts\run_draft_catalog.ps1" -PeriodDir "<期次目录>"

# 阶段B 月刊排版（校验定稿选目→出刊→渲染 PDF/预览→版式体检）
powershell -File "~/.codex/skills/cehui-monthly\scripts\run_monthly_issue.ps1" -PeriodDir "<期次目录>"
```

常用参数：阶段A `-Only 07,14,32,17`／`-From 25`／`-SkipWeekly`／`-LeaderDoc <批注版.doc> -LeaderLabel 0917`；
阶段B `-RebuildTemplate`（重建模板）／`-Forward`（干跑到 `_raw\_forward`，不覆盖正式刊）。日志见 `<期次目录>\_raw\_run_logs\`。

**期次参数**：每期一份 `<期次目录>\99_脚本\period.json`（模板见技能 `assets\period.template.json`），
字段 `issue_dir／window_from／window_to／collect_date／title_range／issue_label／publish_date／editor_unit／leader_label`。
采集窗口、目录抬头日期、期号、封面期号行全部由此驱动，**不要改脚本里的日期**。

**代码与数据分离**：代码只有一份，在 `<工作根 ToolRoot>\99_脚本\`；
期次目录里的 `99_脚本\` 只放该期数据（`period.json`、`catalog_selection*.json` 等）。
运行前脚本会用 `CEHUI_PERIOD_DIR` 定位期次目录（入口脚本已自动设置）。

**十条硬性标准**（每一步都不得违反）：

1. 时间窗口以**原文发布日期**为准；
2. 只保留**三个板块**：政策法规、技术应用类、科技前沿类（2026-09-17 起取消“媒体动态类”）；
3. 每条标注 **10 条业务条线**之一；**摘要必须是实质内容**，不得用模板句；
4. 来源**官网优先、白名单公众号兜底**；正文不得是整页导航或前端模板文本（`is_junk_text()` 判定）；
5. 来源核验**看链接实体**（域名／`__biz`），不看名字；
6. 公众号只能证明**本账号自己发布的内容**；周讯等汇编号一律只作线索；
7. 找不到原文的条目**直接剔除**，不保留标注；
8. 正文必须是**原发布方原文**（官网正文／公众号 `js_content`），周讯 PDF 文本不作正文来源；
9. 同事件多来源**合并为一条**，主链接取官网，其余入交叉来源；
9b. **段落换行必须保留**：正文抓取按块级标签换行（含公众号 `<section>`），成刊排版“一行即一段”，
    不得把源文相邻段落合并（核对点：`02_原文/` 归档与成刊的段落数与原文一致）；
10. **两级产出**：初版约 35 条（政策法规＋科技前沿类≈30%、技术应用类≈70%，
    且包含上一轮领导保留条目）；领导批注后终稿 20—25 条。
11. 不收国际、党建活动、推广宣传、栏目连载、日常调研培训、福建本地内容；**视频／音频／图集／海报等非文字稿不收（只收文字稿）**；
    测绘法宣传日暨国家版图意识宣传周类
    按"收录例外"执行——**只收部级专题稿件与省级做法成效报道**，海报、短视频素材、活动集锦、地市级简讯不收。
12. **目录与成刊只按三个板块（政策法规／技术应用类／科技前沿类）编排，不设二级分类**；
    **2026-09-17 起取消“媒体动态类”**，原该类经验做法稿归技术应用类；业务条线与主题标签只作数据字段与统计维度。
13. **类内排序（R4）**：板块 → 层级（部级→行业与官媒→外省，**层级从国家到地方**）→ 业务中心度
    （**业务从中心到边缘**，依本中心党组半年工作情况汇报章节序）→ 发布日期倒序；优先级 A／B／C 只作字段；
    骨架条目相对顺序不变，补充条目插入到第一条排序键大于它的条目之前。
14. **R8 前沿类门槛**（原 R9 更名）：科技前沿类只收有**技术实质**的内容（方法／指标／模型／成果）；
    产业评论、会议召开这类"看似前沿"的不收。
15. **论文与国际协会奖项例外已取消**：不再保留"前沿论文＋国际协会奖项"，**国际内容一律不收**；
    中国测绘学会"论文摘选"通道停用（仅留档），不再参与候选。

## 二、周期与角色

| 项目 | 规定 |
| --- | --- |
| 采集窗口 | 上月 1 日 00:00 至本期截稿日（示例：2026-08-01 ~ 2026-09-13） |
| 节奏 | 月中启动采集，月底前完成核实与交付；每期留 2 天机动用于回补来源 |
| 采集角色 | 1 人跑脚本、1 人复核抽检（可与撰写人重叠） |
| 复核角色 | 由未参与采集的同事抽检 10 条并签字确认 |

## 三、作业步骤

### S1 建期与准备（0.5 天）

- 新建期次目录（沿用 `2026年8-9月测绘动态资讯/` 结构：`_raw/`、`02_原文/`、`03_参考_山东周讯/`、`99_脚本/`、`Word版/`、`_备查/`）。
- 复制技能模板 `assets\period.template.json` 到 `<期次目录>\99_脚本\period.json`，填写本期窗口、截稿日、期号、发布日、标题日期范围；
  **不要再手改脚本里的 FROM／TO**（03/05/17/23/24/31/32、`sources_whitelist.py`、`编制排版` 均已读该配置）。
- 核对白名单与对照表：`99_脚本/sources_whitelist.py` 的 `SITE_WHITELIST`、`ORG_SITES`、`ORG_WECHAT`、`WECHAT_DIGEST_BIZ`。
- **跑一次标准一致性自检**，确认文档与代码没有漂移（发现不一致必须先改齐再开工）：

```powershell
python 99_脚本/28_check_standard_consistency.py
```

- **输出**：期次目录 + 参数确认。

```powershell
python 99_脚本/04_fetch_details.py             # 抓详情与正文（FORCE=1 强制重取）
```

- 覆盖：自然资源部（测绘／要闻／地方动态）、测绘发展研究中心 8 栏目、国家基础地理信息中心、中国测绘科学研究院、中国测绘学会、中国地理信息产业协会、重点外省（山东、陕西、四川、广东、湖南、江苏、湖北、安徽、广西、浙江）、黑龙江测绘地理信息局（`getDocsByChannel.action` 接口）。
- 中国测绘学会官网"论文摘选"（`csgpc_lwzx`，`https://www.csgpc.org/list/2902.html`）：**2026-09-17 起停用**（论文例外取消），仅留档，不参与候选。
- **判定**：列表页日期仅作线索，详情页日期为准；政府站 GBK/UTF-8 混用由脚本自动处理。
- **输出**：`_raw/<source>.json`、`_raw/<source>_detail.json`。

### S5 自动初筛（0.5 天）

```powershell
python 99_脚本/24_auto_shortlist.py
```

- 对本期新补来源（研究中心、陕西/四川/黑龙江局、湖北厅、广东/江苏/山东厅）+ 部「地方动态」重点省份 + i 自然测绘栏目做关键词初筛，排除党建、巡视、宣传、招聘、培训、走访座谈、表彰等非业务内容。
- **输出**：`_raw/auto_shortlist.json`、`_raw/zrzyb_detail.json`。

### S6 三板块重建与业务条线打标（0.5 天）

```powershell
python 99_脚本/23_rebuild_boards.py
```

- 归并三板块（国家公文并入政策法规；会议与产业动态按主题归入技术应用类／科技前沿类；经验做法稿归技术应用类）；国际、科普与版图宣传、福建本地、日期越界、推广宣传类移入《_备查/未收录条目.md》；按 10 条业务条线打标。
- **输出**：`99_脚本/catalog_selection_boards.json`、`_备查/未收录条目.md`。

### S6.5 领导批注回灌与初版补位（每期固定环节，1 天）

收到领导批注版后按下列顺序执行，规则随批注同步演进：

```powershell
python 99_脚本/29_apply_leader_edits.py      # 解析批注版修订 → _raw/leader_0916.json + 备查报告
python 99_脚本/31_build_draft_selection.py   # 本期终稿直出 16 条；下期起骨架保序 + 按三板块补位
python 99_脚本/30_regression_leader.py       # 回归：骨架完整性、剔除不回流、顺序一致性、删除命中率、新增召回、三板块
```

- **判定**：骨架缺失 0、剔除条目回流 0、顺序异常 0、新增召回 100%、R8 不达标 0、窗口外条目 0、无越界板块；
  R1 命中率不足的删除条目应能归入 R2 人工准则清单。
- **骨架调整记录**：R8 剔除／R3 迁移的条目与理由同时写入《_备查/终稿16条构成说明.md》与回归报告。

### S7 来源实体校验与原文复检（1 天，**汇编成册的关键一步**）

```powershell
python 99_脚本/25_verify_source_entity.py
```

逐条执行：

1. 解析链接域名／`__biz`，与发布单位比对；域名属于其他单位的**自动纠正发布单位**；
2. 公众号 `__biz` 不属于该单位、或命中 `WECHAT_DIGEST_BIZ`（周讯等汇编号）→ **剔除**，写入《_备查/周讯回溯待办.md》；
3. 抓原发布方正文：官网原站、i 自然 `api.iziran.net/api/getArticle`、公众号 `js_content`；
4. 正文不足 200 字或标题要素覆盖率 <0.7 → 标"待补（正文不足）"，保留在目录但**不计入成册**；
5. 同事件标题相似度 ≥0.85 合并为一条，主链接优先官网。

- **输出**：`99_脚本/catalog_selection_final.json`、`_raw/source_entity_check.json`、`_raw/excluded_by_entity.json`、`_备查/来源核验报告.md`、`_备查/待补原文清单.md`、`_备查/周讯回溯待办.md`。
- **判定**：`来源核验报告.md` 中"实体不匹配"必须为 0 或已列入待回溯；"实体不匹配"条目不得出现在目录。

### S8 多方式核实（1 天。**必须早于成稿**）

```powershell
python 99_脚本/08_verify.py        # RECHECK=1 强制重抓
python 99_脚本/09_make_verify_doc.py
```

- 核实方式：链接可达复检、正文回读比对、发布日期核验、交叉来源核验、来源实体核验、浏览器独立渲染复核、人工抽样复核。
- **输出**：`_raw/核实结果.json`、`04_核实记录.md`。
- **判定**：无"待人工复核"遗留，或逐条在核实记录中说明原因。

### S9 成稿与线索池（0.5 天）

```powershell
python 99_脚本/07_build_catalog.py   # 读取 S8 产出的核实结果，写入"核实状态"列
python 99_脚本/14_weekly_pool.py     # 周讯线索池（必须晚于 07，会向 xlsx 追加工作表）
python 99_脚本/09_make_verify_doc.py # 核实记录定稿（放入成稿后的时间戳）
```

- 生成 xlsx（24 字段，含板块、业务条线、来源类型、正文来源、正文长度）、Markdown 目录、`02_原文/<板块>/` 原文归档（正文取"原文正文"）。
- **判定**：归档份数 = 目录条数；正文来源与长度无空值；无"未核实"状态。

### S10 交付件生成（0.5 天）

```powershell
python 99_脚本/17_make_docx.py
```

- 生成 `Word版/`：阅读说明、目录、来源清单、核实记录、周讯线索池、未收录条目备查、采集口径（+ 作业流程）。
- 需要 PDF 时：`18_docx_to_pdf.ps1`（WPS）→ `19_check_pdf.py`（LibreOffice 渲染 + 版式体检）。
- 若某个 docx 正被 Word/预览占用，脚本会跳过该文件并提示，关闭后重跑本步即可。
- **输出**：`Word版/*.docx`、`00_交付说明.md`（手工更新统计与说明）。
- **月刊（三栏目，2026-09-17 起）**：模板与脚本已改为政策法规／技术应用类／科技前沿类三栏目。
  改版或换期时先跑 `编制排版/_build_monthly_template.py` 重建模板，再跑 `编制排版/_make_issue.py`
  （读取 `99_脚本/catalog_selection_final.json`，输出《测绘动态工作_2026年第1期.docx》）。
- **月刊版式要点（2026-09-17 领导确认）**：封面保留《政策要情》同款**红字刊名**（“测绘地理信息月刊”，
  方正小标宋简体 36pt、颜色 C00000、居中文本框）；**正文各栏目页眉**为“栏目名居中＋底边框”，
  并在栏名上方留一空行（页眉整体下移一行），页眉中英文字体统一黑体（`_set_latin_font.py` 默认不再改页眉页脚）。
- **正文三级格式（2026-09-17 依《政策要情》第 100 期核对）**：一级标题黑体小四、二级标题楷体_GB2312 小四加粗、
  正文小标题仿宋_GB2312 小四加粗（仅“标签：”加粗）、正文仿宋_GB2312 小四；`_build_monthly_issue.py` 按行首
  `一、`／`（一）`／`1.` 自动分级。改版后务必重跑 `_build_monthly_template.py` 并抽检三级的字体字号。
- **标题与正文同段**：如“（一）加快构建国家数字空间基准。一是……”，只有到第一个句号为止的标题部分用标题格式，
  其后内容按正文（仿宋_GB2312 小四不加粗）排版；`一、` 与 `（一）` 两级同样处理。
- **成稿文本核校（2026-09-17 增补，人工审核反馈）**：成刊（或领导审核版）出稿后必须过两道：

```powershell
python 99_脚本/27_text_qa.py --doc "<成稿.docx>"            # 体例体检：空格/标点/漏字 + 与原文逐段比对
python 99_脚本/33_fix_docx_text.py "<成稿.docx>" -o "<成稿>_核校版.docx"   # 清多余空格与半角标点（不动版式）
```

  - `27` 输出《_备查/文本体例检查.md》：逐条列出“空格问题／体例问题／原文有而审核版缺／审核版有而原文无”；后两类用于
    判断是**人工有意删除**（署名、图片说明、页面提示）还是**抽取漏字**。
  - `33` 只改 `w:t` 文本节点：清除 `U+00A0／U+200A／U+2004` 等特殊空白、汉字与字母数字之间的空格、中文标点前后的空格，
    汉字间半角标点转全角；**保留**页脚“— 1 —”、目录制表位、法条标题与引号内标语。
  - 复核口径：核校版应满足“汉字与字母/数字之间空格 0、特殊空白仅剩页眉的 `\u3000`、引号书名号括号全部配对”。

## 七、常见问题与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 列表页抓不到条目 | 站点为 JS 渲染 | 找站内接口（如浙江 `jpaas-publish-server`、黑龙江 `getDocsByChannel.action`）或站内检索 |
| 公众号原文找不到 | 搜狗索引稀疏／账号未收录 | ①先查原单位官网；②用浏览器微信搜一搜人工找；③仍找不到→**剔除该条**，写入待回溯 |
| 正文过短 | 页面为视频稿、图片稿或前端渲染 | 换原发媒体接口取正文；仍不足→标"待补"，不进成册 |
| 同事件多条 | 多单位转载、周讯转发 | S7 自动合并；主链接取官网 |
| 发布单位与链接不符 | 部网站转载地方稿、他单位转载 | S7 按链接域名自动纠正发布单位 |
| 日期越界 | 转载滞后、周讯口径不同 | 以原文日期为准；越界条目移入备查 |
| Word 表格报错 | Markdown 单元格含 `|` | 生成脚本已做转义与列数保护 |
| 正文里出现莫名空格（数字/字母/标点旁） | 源页 `&nbsp;`／细空格 `U+200A`／`U+2004`，或复制粘贴带入 | 跑 `33_fix_docx_text.py` 核校成稿；源头由 `normalize_text()` 兜底 |
| 正文整段少了几个字 | 页面家具正则吞掉正文（如旧 `扫一扫[^\n。]{0,16}`） | 改 `BODY_FURNITURE` 为整行匹配；跑 `27_text_qa.py` + 重抓原页按句比对复核 |
| 成稿里出现署名“（刘某）”“××/摄” | 原文末尾的供稿署名 | 由人工审核版决定去留；如需统一删除，在 `33` 中加“文末署名”规则（尚未启用） |
| `powershell -File xx.ps1` 报 ParserError／中文乱码 | .ps1 存成 UTF-8 **无 BOM**，PowerShell 5.1 按 ANSI 读 | 用“UTF-8 带 BOM”重存（仓库里的 .ps1 均已带 BOM；改动后务必确认） |
| 目录页码与实际不符 | 人工增删页后未重排 | 跑 `34_add_toc_links.py`：按页脚“— N —”回填页码（本期修正 45→46、48→49） |
| PDF 里目录点不动 | 目录未加内部超链接，或转换工具未保留 | 跑 `34` 后再导出（LibreOffice/WPS 都会保留内部链接） |
| WPS 里点目录提示“无法打开指定文件” | 用了 Word 原生 `w:hyperlink w:anchor` 写法，WPS 不认 | 用 `34_add_toc_links.py`（默认 `--style field`）重新生成；域写法 WPS/Word 通用 |
| WPS 里页脚页码和目录对不上 | 页脚 `PAGE` 域里的**缓存值过期**（模板自带 1/42/60），WPS 默认不重算 | 跑 `39_fix_footer_page_cache.py`（阶段B 已内置）：刷新缓存＋`updateFields` |
| 页脚页码看着“歪”（偏左、或不同板块高低不一） | 页脚文本框内段落左对齐、且各分节 `pgMar/footer` 不一致（1247 vs 992） | 跑 `40_fix_footer_layout.py`：页码居中＋各节页脚高度统一为 1247 twips |
| 成刊正文出现“原文链接：…” / 文末出现“（刘某）” | 固定规则未生效（用了旧版脚本） | 确认 `_build_monthly_issue.py` 调用了 `WL.include_source_link()` 与 `WL.strip_sign_off()`；重跑阶段B |
| 成刊出现空白页 | 标题前有空段落 + 标题设了“段前分页” | 跑 `38_page_break_per_article.py`（会删掉标题前紧邻空段）；体检项“无空白页”应为 0 |
| 文章接排、没有一篇一页 | 未启用 R12 | 跑 `38_page_break_per_article.py`，或重跑阶段B（新刊默认一篇一页） |
